# InvariantQL

> An invariant remains unchanged under transformation—write data logic once,
> preview it locally, and execute it across file-backed and database sources with
> local or Spark engines.

InvariantQL is currently in its architecture-first design phase. Runtime APIs
and package scaffolding will be added only after the architectural boundaries,
trade-offs, and fitness functions have been agreed.

See the [architecture documentation](docs/architecture/README.md) for the
current system model and decision record.
